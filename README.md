Description:
Developed a predictive model to identify the risk of stroke based on patient health indicators. The dataset included 5,110 records, and models like KNN, Random Forest, and SVC were tested. The KNN model achieved 95.76% accuracy, providing strong early detection potential.

Key Features:
- Data cleaning and preprocessing
- Multiple model comparison
- Accuracy-focused evaluation

Skills & Tools:
Python, Pandas, Scikit-learn, Matplotlib, Supervised Learning, Healthcare Analytics
